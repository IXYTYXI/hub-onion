# 去邮箱可见性改造文档

本目录用于沉淀 ClawHub 当前阶段“去掉基于邮箱的用户流程可见性”需求文档。

本次需求不是删除后端邮箱能力，也不是重构完整认证体系，而是先做一轮明确的产品收口：

- 登录页只保留飞书登录入口
- 删除邮箱辅助登录 UI 和相关文案
- 管理后台不再暴露用户审核能力
- 管理后台不再请求用户审核接口
- 设置页不再公开表达“邮箱绑定决定管理权限资格”
- 飞书授权用户默认自动审核通过
- 后端邮箱接口、审核接口、数据库字段暂时保留

- [需求文档](./requirements.md)
- [技术方案文档](./technical-design.md)

2. 再阅读技术方案文档，确认页面级影响范围、接口可见性收口方式和更细的改动清单
