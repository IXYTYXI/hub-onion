# 首页精选技能、管理配置与安装统计收口需求文档

本目录用于沉淀 ClawHub 当前阶段“首页精选技能与热门技能展示恢复、highlighted 管理能力补齐，以及安装统计展示收口”的需求文档。

当前问题不是单点 bug，而是一组链路断裂：

- 首页“精选技能”和“热门技能”仍使用占位空数组，页面展示为空
- 前端保留了 `highlighted` 概念与筛选参数，但 Go 后端没有对应字段、过滤逻辑和管理接口
- 管理页目前只能删除/恢复 skill，无法配置精选状态
- 管理页 skill 列表中的作者信息仍可能展示为 UID，而不是可读的飞书授权邮箱
- 公开用户页 `/u/:handle` 的用户信息中也仍可能展示 UID 风格 handle，而不是飞书邮箱
- 详情页仍展示“当前安装 / 累计安装”双指标，但 Go 后端没有完整的安装统计模型
- CLI 安装命中了下载接口，但后端当前只累计 `stats_downloads`，没有同步累计 `stats_installs`
- 产品上已经存在“精选技能”展示位，但缺少实际运营入口

本次需求目标是先把这几条链路补齐，使首页、管理后台和详情页统计展示形成可用闭环。
