# 飞书授权接入文档

本目录用于沉淀 ClawHub 在当前 Go 后端架构下接入飞书授权的最终方案文档。

当前确认的产品方向：

- 飞书授权作为主登录方式
- 飞书客户端内优先走 `requestAccess` 免登
- 普通浏览器支持飞书 OAuth 登录，并通过独立认证导航地址发起跳转
- 已有邮箱用户支持绑定飞书身份
- 飞书身份主键使用 `open_id` / `union_id`，不按邮箱自动合并
- 平台会话继续复用现有 `clawhub_session` JWT Cookie
- 设置页仅展示飞书绑定状态、飞书同步邮箱和本地 UID 等业务字段
- 管理权限仍以绑定的邮箱账号为主
- 未绑定邮箱的飞书账号不具备管理权限
- 业务 API 鉴权、CLI Token、管理端接口协议不做破坏性调整
