## Why

当前首页已经提供了快捷安装命令和复制能力，但技能详情页仍只有“下载 ZIP”按钮，缺少针对当前 skill 的直接安装入口。用户在详情页已经完成决策，却还需要自行拼接命令，导致安装主路径不完整且与首页体验不一致。

## What Changes

- 在技能详情页下载按钮下方新增“快捷安装”区域，展示当前 skill 的 CLI 安装命令
- 为该命令增加复制按钮与复制成功反馈，体验与首页现有快捷复制能力保持一致
- 详情页命令生成严格复用现有 env 变量读取与回退逻辑，保持不同环境下 registry 和 CLI 包配置的独立性
- 首页现有快捷安装区域保持不变，不修改其文案、布局或交互

## Capabilities

### New Capabilities
- `skill-detail-quick-install`: 在技能详情页提供基于当前 skill slug 的快捷安装命令展示与复制能力，并要求命令拼接复用现有环境变量规则

### Modified Capabilities

## Impact

- 前端技能详情页头部操作区
- 前端快捷安装命令展示/复制组件
- 命令拼接工具函数的复用边界
- 无后端 API 变更
