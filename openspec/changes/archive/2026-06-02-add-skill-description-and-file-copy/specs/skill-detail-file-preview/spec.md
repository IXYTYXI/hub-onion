## ADDED Requirements

### Requirement: 复制当前预览文件内容
系统 SHALL 允许用户在 skill 详情页文件预览区域复制当前选中文件的完整文本内容。

#### Scenario: 复制已加载文件
- **WHEN** 用户在 skill 详情页文件列表中选中一个文件，且该文件内容已成功加载到预览区域
- **THEN** 系统 SHALL 在文件预览 header 中提供复制按钮
- **WHEN** 用户点击复制按钮
- **THEN** 系统 SHALL 将当前预览文件的完整文本内容写入剪贴板

#### Scenario: 复制成功反馈
- **WHEN** 当前预览文件内容复制成功
- **THEN** 复制按钮 SHALL 短暂显示成功状态
- **THEN** 成功状态结束后按钮 SHALL 恢复为可再次复制的状态

#### Scenario: 没有可复制内容
- **WHEN** 用户尚未选择文件、文件仍在加载，或文件加载失败
- **THEN** 系统 MUST 不允许复制未加载内容或过期内容
- **THEN** 复制按钮 SHALL 不展示或处于不可用状态

#### Scenario: 空文件已加载
- **WHEN** 用户选中的文件已成功加载，且文件文本内容为空字符串
- **THEN** 系统 SHALL 将该文件视为已加载状态，而不是回到未选择提示
- **THEN** 复制按钮 SHALL 按当前文件内容执行复制，并允许写入空字符串

#### Scenario: 切换文件后复制最新内容
- **WHEN** 用户先后选择多个文件并等待最新选中文件加载完成
- **THEN** 复制按钮 SHALL 只复制当前最新选中文件的内容
- **THEN** 系统 MUST 不复制前一个文件的缓存内容作为当前文件内容

#### Scenario: 复制按钮可访问性
- **WHEN** 文件预览 header 展示复制按钮
- **THEN** 按钮 SHALL 提供明确的 `aria-label`
- **THEN** 按钮 SHALL 使用前端文案配置展示“复制”和“已复制”状态
- **THEN** 按钮 SHALL 在窄屏或长文件名场景下不遮挡文件路径、大小或 hash 信息
